[ดาวน์โหลดและวิธีติดตั้ง](https://kruboffice.app/desktop.html) · [KrubOffice บนเว็บ](https://kruboffice.app/) · [เพจ Facebook](https://www.facebook.com/kruboffice/)

**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.6.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.18.0 คิดครับ 0.7.0 และพูดครับ 0.9.0

## ใหม่ในรุ่นนี้

- **แถบเดียวด้านบน ทั้งสามโปรแกรม** แท็บ ชื่อไฟล์ และปุ่มบันทึก เลิกทำ ทำซ้ำ อยู่ในแถบเดียวกัน ได้พื้นที่ทำงานเพิ่ม ชื่อไฟล์อยู่ในกรอบสีทอง คลิกแล้วเห็นชื่อเต็ม สถานะการบันทึก และที่เก็บไฟล์ แตะ Alt (บน Mac คือ Option) หรือกด F10 แล้วกดตัวเลขเพื่อสลับแท็บได้
- **รูปร่าง 182 แบบ และแผงแผนภูมิ ทั้งสามโปรแกรม** เมนูแทรก › รูปร่าง มีรูปร่างมาตรฐานครบทุกหมวดพร้อมชื่อภาษาไทย คลิกแผนภูมิแล้วจัดสีพื้น เส้นขอบ เงา แสงเรือง และข้อความของแต่ละส่วนได้ ลักษณะเส้นทุกที่แสดงเป็นเส้นจริง
- **หน้าต่างเกี่ยวกับ และแผงด้านข้างแบบแผงย่อย** หน้าตาเดียวกันทั้งชุด
- **เขียนครับ 0.18.0** ไดอะแกรม 19 แบบ ปากกาวาดเส้นตาราง ลากข้อความที่เลือกไปวาง กำหนดสัญลักษณ์หัวข้อย่อยใหม่ หัวกระดาษและท้ายกระดาษเป็นแผงด้านข้าง สารบัญใช้เลขหน้าแบบ ก ข หรือเลขไทยตามท้ายกระดาษ บอกแหล่งดาวน์โหลดฟอนต์ที่ขาด (เช่น ฟอนต์แห่งชาติของ SIPA) บันทึกรูปภาพออกเป็นไฟล์ และพิมพ์ในเอกสารยาวเร็วขึ้นประมาณ 5 เท่าเมื่อเปิดตรวจสะกด
- **คิดครับ 0.7.0** PDF ภาษาไทยจากโปรแกรมบนเครื่องถูกต้องแล้ว (รุ่น 0.5.0 ตัวไทยยังกลายเป็นตัวจีน) วันที่แบบยาวภาษาไทยปี พ.ศ. ลากเปลี่ยนช่วงในสูตรได้แบบ Excel หมุนรูปร่างด้วยเมาส์ หน้าต่างเรียงลำดับแบบกำหนดเองแบบใหม่ และตัวไทยบน Windows ไม่ตกต่ำกว่าตัวเลขอีก
- **พูดครับ 0.9.0** เปิดไฟล์ PowerPoint รุ่นเก่า (.ppt) ส่งออกทุกสไลด์เป็นรูป PNG หรือ JPEG ตั้งฟอนต์ไทยแยกจากฟอนต์อังกฤษ หน้าต่างแทรกไดอะแกรมแบบใหม่ บันทึกรูปภาพ วิดีโอ และเสียงออกเป็นไฟล์ และภาพเคลื่อนไหวรอให้การเปลี่ยนสไลด์จบก่อน
- **ปลอดภัยขึ้น** ทั้งสามโปรแกรมรับการแก้ไขด้านความปลอดภัยจากโครงการต้นทาง ไฟล์ที่เสียหายหรือจงใจสร้างมาให้โปรแกรมค้างถูกจำกัดไว้แล้ว และการบันทึกไฟล์เขียนลงดิสก์ครบก่อนแทนที่ไฟล์เดิม
- **บน Windows** หน้าเริ่มต้นของ KrubOffice ใช้ DirectX 12 แบบเดียวกับทั้งสามโปรแกรม เพื่อแก้ปัญหาเปิดไม่ขึ้นบนโน้ตบุ๊กบางรุ่นที่มีการ์ดจอ AMD คู่กับ NVIDIA ([#4](https://github.com/chanonss/kruboffice-desktop/issues/4))

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของ[เขียนครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.18.0.md) [คิดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.7.0.md) และ[พูดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/phutkrub/v0.9.0.md)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.6.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.6.0-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.6.0_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.6.0-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.6.0-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.6.0_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.6.0-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.6.0-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
