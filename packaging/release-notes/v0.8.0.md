**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.8.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.20.0 คิดครับ 0.8.0 และพูดครับ 0.10.0

## ใหม่ในรุ่นนี้

- **หน้าเริ่มต้นใหม่** เปิด KrubOffice แล้วเห็นไฟล์ล่าสุดของทั้งสามโปรแกรมเป็นการ์ด บอกชื่อไฟล์ โปรแกรม และโฟลเดอร์ กรองตามชนิดไฟล์ ปักหมุดไฟล์ที่ใช้บ่อย และค้นหาชื่อไฟล์ได้ ปุ่ม **+ เอกสาร** **+ ตาราง** **+ งานนำเสนอ** ด้านบนเปิดโปรแกรมนั้นทันที
- **รุ่นพกพาสำหรับ Windows** แตกไฟล์ zip ลงแฟลชไดรฟ์แล้วเปิดใช้ได้เลยโดยไม่ต้องติดตั้ง การตั้งค่าและไฟล์ล่าสุดเก็บไว้ในโฟลเดอร์ data ข้างโปรแกรม ไม่ทิ้งอะไรไว้ในเครื่อง
- **คิดครับและพูดครับ: ไอคอนมีสี** แบบเดียวกับเขียนครับ ทุกไอคอนแต้มสีเฉพาะส่วนที่สำคัญ หาปุ่มได้เร็วขึ้น
- **คิดครับ: เติมอัตโนมัติภาษาไทย** ลากจุดเติมเพื่อเรียงชื่อวัน ชื่อเดือน ปีนักษัตร ไตรมาส และตัวเลขไทยต่อกัน
- **คิดครับและพูดครับ: มุมโค้งและล็อกวัตถุ** ปรับรัศมีมุมของสี่เหลี่ยมมุมมน และล็อกรูปภาพหรือรูปร่างไม่ให้ขยับโดยไม่ตั้งใจ
- **คิดครับและพูดครับ: กล่องโต้ตอบและแผงด้านข้างหน้าตาเดียวกับเขียนครับ** เนื้อหาอยู่บนการ์ดสีขาว ปุ่มอยู่แถวล่างเสมอ หัวข้อในแผงอ่านง่ายขึ้น

## แก้ไขในรุ่นนี้

- **หน้าเริ่มต้นแสดงไฟล์ล่าสุดของเขียนครับครบ** ตั้งแต่เขียนครับ 0.19 ย้ายที่เก็บการตั้งค่า ไฟล์ที่เพิ่งเปิดในเขียนครับจึงไม่ขึ้นในหน้าเริ่มต้น ตอนนี้ขึ้นแล้ว

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของ[คิดครับ 0.8.0](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.8.0.md) และ[พูดครับ 0.10.0](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/phutkrub/v0.10.0.md) เขียนครับยังเป็นรุ่น 0.20.0 เท่ากับรุ่นก่อน

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.8.0-windows-x64.msi`
- **Windows รุ่นพกพา** (ไม่ต้องติดตั้ง): `KrubOffice-0.8.0-windows-x64-portable.zip`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.8.0-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.8.0_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.8.0-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.8.0-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway รุ่นพกพาให้คลิกขวาที่ไฟล์ zip › Extract All แล้วเปิด `kruboffice.exe` ในโฟลเดอร์ KrubOffice ที่แตกออกมา ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.8.0_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.8.0-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.8.0-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
