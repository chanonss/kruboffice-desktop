**KrubOffice สำหรับ Windows และ macOS รุ่น 0.2.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.14.0 พูดครับ 0.6.0 และคิดครับ 0.4.0

## ใหม่ในรุ่นนี้

- **มีรุ่นสำหรับ macOS แล้ว** แอปเดียวใช้ได้ทั้ง Mac ชิป Apple และ Mac ชิป Intel ผ่านการตรวจของ Apple (notarized) เปิดได้ทันทีโดยไม่มีข้อความเตือน ดาวน์โหลดไฟล์ .dmg แล้วลาก KrubOffice ไปไว้ในโฟลเดอร์ Applications
- **เขียนครับบอกเมื่อเครื่องไม่มีฟอนต์ที่เอกสารใช้** ช่องฟอนต์มีเครื่องหมาย ▲ สีส้ม ชี้ค้างไว้จะบอกว่าแสดงด้วยฟอนต์อะไรแทน และแถบสถานะขึ้นว่า **ไม่ได้ติดตั้งฟอนต์ N ตัว** คลิกดูรายชื่อและกด **เพิ่มฟอนต์…** ได้ TH SarabunPSK กับ TH Sarabun New ใช้แทนกันได้โดยไม่เตือน
- **เขียนครับจัดย่อหน้าภาษาไทยตรงกับ Word มากขึ้น** หนังสือราชการที่ย่อหน้าด้วยการเคาะวรรค เมื่อจัดชิดขอบหรือกระจายแบบไทย ตัวอักษรแรกอยู่ตรงเหมือนใน Word ชื่อวันตรงกับวันที่ในไทย และไฟล์ .docx เก็บการตั้งค่าได้ครบขึ้น
- **คัดลอกไปวางในโปรแกรมอื่นแล้วรูปแบบยังอยู่มากขึ้น** คัดลอกจากเขียนครับจะส่งข้อความแบบ RTF ไปด้วย โปรแกรมอย่าง WordPad และ Outlook จึงได้ตัวหนา ตัวเอียง และฟอนต์ตามต้นฉบับ
- **Alt+ตัวเลขในช่องค้นหาและช่องอื่น ๆ** พิมพ์อักขระพิเศษด้วย Alt+ตัวเลขบนแป้นตัวเลขได้ในช่องค้นหาและช่องในหน้าต่างต่าง ๆ เหมือนในหน้าเอกสาร
- **หน้าต่างไม่หายไปนอกจอ** หน้าต่างที่เคยเปิดไว้บนจอที่ถอดออกไปแล้ว จะกลับมาเปิดกลางจอหลัก
- **พูดครับ** ปุ่มบนแท็บนำเสนอและระหว่างฉายสไลด์เป็นภาษาไทย และคัดลอกวางรูปได้ดีขึ้น
- **คิดครับ** มีตัวควบคุมฟอร์ม (ปุ่ม แถบเลื่อน ปุ่มหมุน) และแก้ปัญหาโปรแกรมหยุดทำงานตอนวางข้อมูลทั้งคอลัมน์

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.2.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.2.0-macos-universal.dmg`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
