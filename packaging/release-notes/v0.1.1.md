**KrubOffice สำหรับ Windows รุ่น 0.1.1 (รุ่นทดลอง)**

## แก้ไขในรุ่นนี้

- **เปิดโปรแกรมได้บน Windows ทุกเครื่อง** รุ่น 0.1.0 เปิดไม่ได้ในเครื่องที่ไม่มี Visual C++ Redistributable ของ Microsoft ติดตั้งอยู่ โดยขึ้นข้อความว่า "VCRUNTIME140.dll was not found" รุ่นนี้รวมส่วนที่จำเป็นไว้ในโปรแกรมแล้ว ไม่ต้องติดตั้งอะไรเพิ่ม

- **เขียนครับไม่ถามเรื่องตรวจหารุ่นใหม่แล้ว** รุ่น 0.1.0 อาจถามว่าจะให้ตรวจหารุ่นใหม่หรือไม่ ซึ่งเป็นการตรวจของเขียนครับรุ่นเดิมก่อนรวมเป็น KrubOffice รุ่นนี้นำออกแล้ว ทั้งสามโปรแกรมไม่ติดต่ออินเทอร์เน็ตเอง ข่าวรุ่นใหม่ดูได้ที่ kruboffice.app และเพจ Facebook ของ KrubOffice

หากติดตั้งรุ่น 0.1.0 ไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.1.1-windows-x64.msi`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้ง Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html) รุ่นสำหรับ macOS จะตามมาภายหลัง
