**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.6.1 (รุ่นทดลอง)**

รวมเขียนครับ 0.18.1 คิดครับ 0.7.1 และพูดครับ 0.9.1 รุ่นแก้ไขเล็กน้อยต่อจากรุ่น 0.6.0

## ใหม่ในรุ่นนี้

- **แม่แบบบัญชีวัด 3 แบบในเขียนครับ** ไฟล์ › สร้าง มีแบบที่ 1 บัญชีรายรับ-รายจ่าย (เงินสด) แบบที่ 2 บัญชีรายรับ-รายจ่าย (บัญชีธนาคาร) และแบบที่ 3 รายงานเงินคงเหลือ

## แก้ไขในรุ่นนี้

- **ไอคอนเขียนครับบน Windows เป็นโลโก้จริง** ไฟล์โปรแกรม แถบงาน และตัวติดตั้งใช้โลโก้ตัว ข แก้วสีทอง แบบเดียวกับคิดครับและพูดครับ
- **โลโก้จริงในหน้าต่างเกี่ยวกับ** ทั้งสามโปรแกรมแสดงโลโก้ของโปรแกรม แทนตัวอักษรบนสี่เหลี่ยมสี
- **เขียนครับ** ลบตัวแบ่งส่วนด้วย Backspace หรือ Delete ได้ แทรกตัวแบ่งส่วนแบบหน้าถัดไปแล้วพิมพ์ต่อที่ต้นหน้าใหม่ได้ทันที ลากข้อความเห็นสำเนาจาง ๆ ตามตัวชี้ วางเซลล์ตารางทับเซลล์เดิมแทนการซ้อนตาราง เส้นขอบตารางไม่ยื่นเลยมุม ตัวคัดลอกรูปแบบมีรูปแปรงข้างตัวชี้ และกด Esc ออกจากตัวอย่างก่อนพิมพ์ได้

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของ[เขียนครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.18.1.md) [คิดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.7.1.md) และ[พูดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/phutkrub/v0.9.1.md)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.6.1-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.6.1-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.6.1_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.6.1-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.6.1-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.6.1_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.6.1-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.6.1-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
