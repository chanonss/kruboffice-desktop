**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.4.1 (รุ่นทดลอง)**

รวมเขียนครับ 0.16.0 คิดครับ 0.5.0 และพูดครับ 0.7.0 (โปรแกรมรุ่นเดียวกับ KrubOffice 0.4.0)

## ใหม่ในรุ่นนี้

- **KrubOffice ใช้บน Linux ได้แล้ว** เริ่มที่ Linux Mint 21 ขึ้นไป และใช้ได้บน Ubuntu 22.04 ขึ้นไปและ Debian 12 ขึ้นไปด้วย ติดตั้งจากไฟล์ .deb ไฟล์เดียว ได้ครบทั้งเขียนครับ คิดครับ และพูดครับ
- **เปิดจากเมนูหลักได้ทันที** KrubOffice อยู่ในหมวด Office ของเมนูหลัก คลิกขวาที่ไฟล์ .docx .xlsx หรือ .pptx แล้วเลือกเปิดด้วย KrubOffice ได้ และแต่ละโปรแกรมแสดงชื่อกับไอคอนของตัวเองบนแถบงาน

บน Windows และ macOS รุ่นนี้เหมือนรุ่น 0.4.0 ทุกอย่าง ไม่ต้องอัปเดตก็ได้

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.4.1-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.4.1-macos-universal.dmg`
- **Linux** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.4.1_amd64.deb`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ติดตั้งบน Linux Mint: ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.4.1_amd64.deb` ในโฟลเดอร์ที่ดาวน์โหลดไว้ ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
