[ดาวน์โหลดและวิธีติดตั้ง](https://kruboffice.app/desktop.html) · [KrubOffice บนเว็บ](https://kruboffice.app/) · [เพจ Facebook](https://www.facebook.com/kruboffice/)

**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.8.1 (รุ่นทดลอง)**

รวมเขียนครับ 0.21.1 คิดครับ 0.8.2 และพูดครับ 0.10.2 รุ่นเดียวกับบนเว็บ

## ใหม่ในรุ่นนี้

- **เลือกตัวชี้เมาส์ได้ 8 แบบ** ลูกศรสีขาว สีดำ สีทอง ลูกศรขนาดใหญ่ และรูปแมว กระต่าย ลูกเจี๊ยบ ช้าง ตั้งได้ที่ **ตั้งค่า › ตัวชี้เมาส์** ในหน้าเริ่มต้น และที่ **ตัวเลือก › ทั่วไป** ในแต่ละโปรแกรม เปลี่ยนเฉพาะลูกศร ตัวชี้ตอนพิมพ์ข้อความ ชี้ลิงก์ และปรับขนาดยังเป็นแบบของระบบ ค่าเริ่มต้นยังเป็นลูกศรของระบบเหมือนเดิม
- **คิดครับและพูดครับ: เปลี่ยนชื่อไฟล์ได้จากเมนูชื่อไฟล์** คลิกชื่อไฟล์ด้านบนแล้วเลือก **เปลี่ยนชื่อ…** เหมือนในเขียนครับ ไฟล์ที่บันทึกไว้แล้วจะเปลี่ยนชื่อในโฟลเดอร์เดิม

## แก้ไขในรุ่นนี้

- **เขียนครับบน Mac: กด ⌘V แล้วข้อความไม่ถูกวางซ้ำสองครั้งอีก** เดิมคัดลอกข้อความแล้วกด ⌘V ข้อความจะถูกวางสองครั้งทุกครั้ง ตอนนี้วางครั้งเดียวตามปกติ
- **ทั้งสามโปรแกรมบน Mac: ปุ่มหน้าต่างอยู่ในแนวเดียวกับแถบด้านบน** ปุ่มปิด ย่อ และขยายหน้าต่าง (ปุ่มสีสามปุ่มมุมซ้ายบน) อยู่ตรงกลางแถบด้านบนพอดี

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของเขียนครับ [0.21.1](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.21.1.md) คิดครับ [0.8.2](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.8.2.md) และพูดครับ [0.10.2](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/phutkrub/v0.10.2.md)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.8.1-windows-x64.msi`
- **Windows รุ่นพกพา** (ไม่ต้องติดตั้ง): `KrubOffice-0.8.1-windows-x64-portable.zip`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.8.1-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.8.1_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.8.1-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.8.1-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway รุ่นพกพาให้คลิกขวาที่ไฟล์ zip › Extract All แล้วเปิด `kruboffice.exe` ในโฟลเดอร์ KrubOffice ที่แตกออกมา ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.8.1_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.8.1-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.8.1-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
