[ดาวน์โหลดและวิธีติดตั้ง](https://kruboffice.app/desktop.html) · [KrubOffice บนเว็บ](https://kruboffice.app/) · [เพจ Facebook](https://www.facebook.com/kruboffice/)

**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.5.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.17.0 คิดครับ 0.6.0 และพูดครับ 0.8.0

## ใหม่ในรุ่นนี้

- **แบบ .rpm สำหรับ Fedora และดิสโทรตระกูล rpm** ติดตั้งได้บน Fedora 36 ขึ้นไปแบบ 64 บิต (ทดสอบติดตั้งแล้ว) และดิสโทรตระกูล rpm อื่นที่ใหม่พอ เช่น openSUSE Tumbleweed คู่กับ .deb (Linux Mint, Ubuntu, Debian) และ AppImage (ดิสโทรอื่น) ทั้งสามแบบมีโปรแกรมชุดเดียวกัน
- **แผงด้านขวาแทนแท็บของวัตถุ ทั้งสามโปรแกรม** คลิกที่ตาราง รูปภาพ รูปร่าง หรือแผนภูมิ แล้วแผงจัดรูปแบบจะเปิดทางขวาเอง แผงรูปร่างแบ่งเป็นหมวด พื้นที่ เส้น เอฟเฟกต์ และตำแหน่งและขนาด เหมือนกันทุกโปรแกรม
- **หน้าตาเดียวกันทั้งชุด** ไฟล์ › ตัวเลือก จัดเป็นหมวด แถบด้านบน (บันทึก เลิกทำ ทำซ้ำ) และความสูงของแถบเครื่องมือเท่ากันทุกโปรแกรม ปักหมุดฟอนต์ที่ใช้บ่อยไว้บนสุดของรายการได้ และไอคอนส่วนใหญ่มาจากชุด Tabler Icons
- **เขียนครับ 0.17.0** หน้าต่างอักขระตั้งฟอนต์ไทยและอังกฤษแยกกัน ฝังฟอนต์ไว้ในไฟล์ .docx คำบรรยายภาพและตารางแบบไทยเป็นค่าเริ่มต้น และตัวคัดลอกรูปแบบทาลงช่องตารางได้
- **คิดครับ 0.6.0** พิมพ์และส่งออก PDF เป็นภาษาไทยได้ถูกต้อง พิมพ์เฉพาะเซลล์ที่เลือก และรูปร่างมีเงา แสงเรือง ขอบนุ่ม ความโปร่งใส เส้นประ หัวลูกศร หมุน และพลิก
- **พูดครับ 0.8.0** มุมมองผู้นำเสนอบนจอที่สอง ฝังฟอนต์ไว้ในไฟล์ .pptx และ Cmd+D หรือ Ctrl+D ทำสำเนาสไลด์
- **หน้าเริ่มต้นของ KrubOffice ใช้ฟอนต์ของระบบ** ตัวหนังสือเข้ากับเครื่อง (SF และ Thonburi บน macOS, Segoe UI และ Leelawadee UI บน Windows, ฟอนต์ของเดสก์ท็อปบน Linux)
- **บน macOS** ไอคอนใน Dock ไม่เปลี่ยนรูปตอนเปิดโปรแกรมแล้ว และแถบเครื่องมือของหน้าตัวอย่างก่อนพิมพ์ในเขียนครับไม่ทับปุ่มปิด ย่อ ขยายหน้าต่างอีก

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของ[เขียนครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.17.0.md) [คิดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.6.0.md) และ[พูดครับ](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/phutkrub/v0.8.0.md)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.5.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.5.0-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.5.0_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.5.0-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.5.0-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.5.0_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.5.0-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.5.0-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
