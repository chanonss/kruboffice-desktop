[ดาวน์โหลดและวิธีติดตั้ง](https://kruboffice.app/desktop.html) · [KrubOffice บนเว็บ](https://kruboffice.app/) · [เพจ Facebook](https://www.facebook.com/kruboffice/)

**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.4.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.16.0 คิดครับ 0.5.0 และพูดครับ 0.7.0

## ใหม่ในรุ่นนี้

- **เพิ่มเมื่อ 14 พ.ย. 2569: ใช้บน Linux ได้แล้ว** เริ่มที่ Linux Mint 21 ขึ้นไป และใช้ได้บน Ubuntu 22.04 ขึ้นไปและ Debian 12 ขึ้นไปด้วย ติดตั้งจากไฟล์ .deb ไฟล์เดียว ได้ครบทั้งเขียนครับ คิดครับ และพูดครับ เปิดได้จากเมนูหลักหมวด Office โปรแกรมรุ่นเดียวกับบน Windows และ macOS
- **ไอคอนชุดใหม่ มาตรฐานเดียวกันทั้งสามโปรแกรม** ไอคอนวาดใหม่เป็นเส้นบางแบบเดียวกัน ปุ่มที่ทำงานเหมือนกันหน้าตาเหมือนกันทั้งเขียนครับ คิดครับ และพูดครับ
- **แถบเครื่องมือแบบใหม่** ปุ่มสองขนาด ไม่เกินสองแถว คำสั่งหลักเป็นปุ่มใหญ่มีชื่อกำกับ ปุ่มเล็กชี้ค้างไว้เพื่อดูชื่อ เหลือพื้นที่ทำงานมากขึ้น
- **เขียนครับ 0.16.0** พับเป็นเล่ม ปุ่มเลขไทย ซ่อนเลขหน้าเฉพาะหน้า (คลิกขวาที่ท้ายกระดาษ) และช่องขนาดรูปภาพ รูปร่าง และแผนภูมิ
- **คิดครับ 0.5.0** สมุดงานใหม่ใช้ฟอนต์ Sarabun ย้ายหรือคัดลอกชีตไปสมุดงานอื่น แท็บรูปแบบรูปภาพและรูปร่าง และช่องฟอนต์แสดงฟอนต์ที่ติดตั้งในเครื่อง
- **พูดครับ 0.7.0** เลือกภาษาของโปรแกรมได้ใน ไฟล์ › ตัวเลือก และแท็บของรูปภาพ ตาราง และ SmartArt เรียบร้อยขึ้น

รายละเอียดของแต่ละโปรแกรมอยู่ในหมายเหตุการออกรุ่นของ[เขียนครับ](https://github.com/chanonss/khiankrub-web/releases/tag/v0.16.0) [คิดครับ](https://github.com/chanonss/khitkrub-web/releases/tag/v0.5.0) และ[พูดครับ](https://github.com/chanonss/phutkrub-web/releases/tag/v0.7.0)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.4.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.4.0-macos-universal.dmg`
- **Linux** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.4.0_amd64.deb`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.4.0_amd64.deb` ในโฟลเดอร์ที่ดาวน์โหลดไว้ ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
