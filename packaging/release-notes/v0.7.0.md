[ดาวน์โหลดและวิธีติดตั้ง](https://kruboffice.app/desktop.html) · [KrubOffice บนเว็บ](https://kruboffice.app/) · [เพจ Facebook](https://www.facebook.com/kruboffice/)

**KrubOffice สำหรับ Windows, macOS และ Linux รุ่น 0.7.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.20.0 คิดครับ 0.7.2 และพูดครับ 0.9.1

## ใหม่ในรุ่นนี้

- **เขียนครับ หน้าตาใหม่ พื้นที่เขียนกว้างขึ้น** แท็บย้ายขึ้นไปอยู่บนแถบสีด้านบน ปุ่มคำสั่งเรียงเป็นแถวเดียวเต็มความกว้างหน้าต่าง ปุ่มที่เหลืออยู่ในปุ่ม **เพิ่มเติม** ท้ายแถว ลากปุ่มที่ใช้บ่อยขึ้นไปวางบนแถบเองได้ และกด **คืนค่า** เพื่อกลับเป็นแบบเดิม
- **เขียนครับ ไอคอนมีสี** ทุกไอคอนแต้มสีเฉพาะส่วนที่สำคัญ เช่น ถังขยะสีแดง เครื่องหมายบวกสีเขียว ช่วยให้หาปุ่มได้เร็วขึ้น
- **เขียนครับ แผงสารบัญแบบรายงานวิชาการไทย** การอ้างอิง › แทรกสารบัญ สร้างและปรับสารบัญ สารบัญภาพ และสารบัญตาราง ได้ในที่เดียว เลือกเค้าโครงรายงานวิชาการไทยได้ (หัวเรื่องกลางหน้า คำว่า "หน้า" เหนือเลขหน้า และ "สารบัญ (ต่อ)" ทุกหน้าถัดไป)
- **เขียนครับ หัวกระดาษและท้ายกระดาษหมุนตามหน้าแนวนอน** เลขหน้าอยู่ตำแหน่งเดียวกับหน้าอื่นเมื่อเย็บเล่ม
- **เขียนครับ วางตารางจาก Word ได้ครบขึ้น** มาพร้อมความกว้างคอลัมน์ เส้นขอบ และสีพื้นของเซลล์ และเลือกรูปแบบการวางได้จากเมนูคลิกขวา
- **เขียนครับ มุมโค้งของสี่เหลี่ยมมุมมน และล็อกวัตถุ** ปรับรัศมีมุมได้ที่แผงรูปร่าง หรือลากจุดสีทองที่มุม และล็อกรูปภาพหรือรูปร่างไว้ไม่ให้ถูกย้ายหรือแก้ไขโดยไม่ตั้งใจ
- **เขียนครับ กล่องโต้ตอบและแผงด้านข้างหน้าตาเดียวกันทั้งโปรแกรม** แถบสมการและแถบเค้าร่างเป็นแถวเดียว แถบเค้าร่างเป็นภาษาไทย และดูแผงการนำทาง › หน้า แบบหน้าคู่ได้

## แก้ไขในรุ่นนี้

- **เขียนครับ ข้อความภาษาไทยที่วางจาก Word หรือเว็บไม่กระจายห่างอีก** เดิมบางบรรทัดตัวอักษรถูกดึงห่างทีละตัว ตอนนี้ย่อหน้าที่วางมาใช้การจัดแนวเดิมของต้นฉบับ
- **เขียนครับ** วางข้อความลงหลายเซลล์ของตารางพร้อมกันได้ เลขหน้าต่อเนื่องหลังตัวแบ่งส่วนแบบหน้าถัดไป ปุ่มเชื่อมกับส่วนก่อนหน้ากดครั้งเดียวก็ยกเลิกได้ และชื่อฟอนต์ยาวไม่ล้นช่อง
- **คิดครับ** ตัวอย่างก่อนพิมพ์แสดงรูปภาพและวัตถุอื่นในแผ่นงานครบ ตรงกับไฟล์ PDF ที่ส่งออก

รายละเอียดของแต่ละโปรแกรมอยู่ในบันทึกรุ่นของเขียนครับ [0.19.0](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.19.0.md) และ [0.20.0](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khiankrub/v0.20.0.md) และ[คิดครับ 0.7.2](https://github.com/chanonss/kruboffice-desktop/blob/main/release-notes/khitkrub/v0.7.2.md) พูดครับยังเป็นรุ่น 0.9.1 เท่ากับรุ่นก่อน

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.7.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.7.0-macos-universal.dmg`
- **Linux Mint, Ubuntu, Debian** (Linux Mint 21 ขึ้นไป, Ubuntu 22.04 ขึ้นไป, Debian 12 ขึ้นไป แบบ 64 บิต): `kruboffice_0.7.0_amd64.deb`
- **Fedora และดิสโทรตระกูล rpm** (Fedora 36 ขึ้นไปแบบ 64 บิต และดิสโทรตระกูล rpm อื่นที่ใช้ glibc 2.35 ขึ้นไป): `kruboffice-0.7.0-1.x86_64.rpm`
- **Linux ดิสโทรอื่น** (AppImage แบบ 64 บิต ไม่ต้องติดตั้ง): `KrubOffice-0.7.0-x86_64.AppImage`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ติดตั้งบน Linux Mint ให้ดับเบิลคลิกไฟล์ .deb แล้วกด Install Package หรือใช้คำสั่ง `sudo apt install ./kruboffice_0.7.0_amd64.deb` บน Fedora ใช้คำสั่ง `sudo dnf install ./kruboffice-0.7.0-1.x86_64.rpm` (openSUSE ใช้ `sudo zypper install ./kruboffice-0.7.0-1.x86_64.rpm`) ในโฟลเดอร์ที่ดาวน์โหลดไว้ ส่วน AppImage ให้คลิกขวาที่ไฟล์ › Properties › Permissions ติ๊ก Allow executing file as program แล้วดับเบิลคลิก ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
