**KrubOffice สำหรับ Windows และ macOS รุ่น 0.3.0 (รุ่นทดลอง)**

รวมเขียนครับ 0.15.0 พูดครับ 0.6.0 และคิดครับ 0.4.0

## ใหม่ในรุ่นนี้

เขียนครับอัปเดตเป็น 0.15.0 ส่วนพูดครับและคิดครับเป็นรุ่นเดิม

- **ตัวอย่างงานพิมพ์เลื่อนต่อเนื่อง** เลื่อนดูทุกหน้าต่อกันได้ทั้งแบบหน้าเดียวและหน้าคู่ และกดแท็บ **ไฟล์** หลังปิดตัวอย่างก่อนพิมพ์ จะเข้าหน้าไฟล์ตามปกติ
- **คุณสมบัติของตารางครบขึ้น** กำหนดความกว้างทุกคอลัมน์ ให้ตารางอยู่หน้าเดียวกับย่อหน้าถัดไป เลือกชนิด ความหนา และสีของเส้นขอบ และใส่สีพื้นให้เซลล์ แถว หรือทั้งตาราง
- **แกลเลอรีสไตล์ตารางมีแผงเลือกเพิ่ม** กดปุ่ม **เพิ่มเติม** เพื่อดูสไตล์ทั้งหมดแยกเป็นตารางธรรมดา ตารางแบบมีเส้น และตารางแบบรายการ ตัวอย่างใหญ่ขึ้นและเต็มช่อง
- **แท็บมุมมองและบานหน้าต่างสไตล์เรียบร้อยขึ้น** ชื่อปุ่มสองบรรทัด กลุ่มแสดงสามแถว บานหน้าต่างสไตล์ใช้พื้นที่น้อยลง และแก้ไขสไตล์เป็นภาษาไทยครบขึ้น
- **ริบบิ้นเรียบง่ายขึ้นตั้งแต่เปิดใช้** แท็บ วาด, จดหมาย, ช่วยเหลือ, นักพัฒนา และ Zotero ซ่อนไว้ก่อน เปิดได้ใน **ปรับแต่งริบบิ้น**

รายละเอียดทั้งหมดของเขียนครับ 0.15.0 อยู่ใน[หมายเหตุการออกรุ่นของเขียนครับ](https://github.com/chanonss/khiankrub-web/releases/tag/v0.15.0)

หากติดตั้งรุ่นก่อนไว้แล้ว ดาวน์โหลดรุ่นนี้มาติดตั้งทับได้เลย ไม่ต้องถอนรุ่นเดิมก่อน

## ไฟล์สำหรับดาวน์โหลด

- **Windows** (Windows 10 และ 11 แบบ 64 บิต): `KrubOffice-0.3.0-windows-x64.msi`
- **macOS** (macOS 11 ขึ้นไป ทั้งชิป Apple และ Intel): `KrubOffice-0.3.0-macos-universal.dmg`
- `SHA256SUMS` สำหรับตรวจสอบไฟล์

ตอนติดตั้งบน Windows อาจเตือนก่อน ให้กด More info แล้วกด Run anyway ดูวิธีทีละขั้นได้ที่[หน้าวิธีติดตั้ง](https://kruboffice.app/desktop.html)
