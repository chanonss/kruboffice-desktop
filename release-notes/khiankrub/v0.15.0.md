# KhianKrub Web v0.15.0

_เผยแพร่ 9 พ.ย. 2569 · Published 2026-11-09_

9 พฤศจิกายน 2569
[เปิดใช้งาน KhianKrub](https://khiankrub.app/) · [KrubOffice](https://kruboffice.app/)

**เขียนครับบนเว็บ (KhianKrub Web) รุ่น 0.15.0**

## ใหม่ในรุ่นนี้

- **ตัวอย่างงานพิมพ์เลื่อนต่อเนื่อง** ในมุมมองตัวอย่างก่อนพิมพ์ เลื่อนดูทุกหน้าต่อกันได้ทั้งแบบหน้าเดียวและแบบหน้าคู่ (ติ๊ก **เลื่อนต่อเนื่อง** บนแถบเครื่องมือ เปิดไว้ให้ตั้งแต่ต้น) และกดแท็บ **ไฟล์** หลังปิดตัวอย่างก่อนพิมพ์ จะเข้าหน้าไฟล์ตามปกติ ไม่เด้งกลับไปตัวอย่างอีก
- **คุณสมบัติของตาราง ครบขึ้น** หน้าต่างแบ่งเป็นหน้าย่อยทางซ้าย มีปุ่มรีเซ็ต กำหนดความกว้างของทุกคอลัมน์ได้ในหน้าคอลัมน์ ติ๊ก **ให้อยู่หน้าเดียวกับย่อหน้าถัดไป** ได้ในหน้าการไหลของข้อความ เส้นขอบเลือกชนิด ความหนา และสีได้ และใส่สีพื้นให้เซลล์ แถว หรือทั้งตาราง การเปลี่ยนทั้งหมดเป็นการแก้ไขครั้งเดียวที่เลิกทำได้ครั้งเดียว
- **แท็บออกแบบตาราง: แกลเลอรีสไตล์ตารางแบบมีแผงเลือกเพิ่ม** ไม่ต้องเลื่อนไปทางซ้ายขวาอีก กดลูกศรหรือปุ่ม **เพิ่มเติม** เพื่อเปิดแผงที่แสดงสไตล์ทั้งหมดแยกเป็นตารางธรรมดา ตารางแบบมีเส้น และตารางแบบรายการ ตัวอย่างแต่ละช่องใหญ่ขึ้นและเต็มช่อง พร้อมปุ่มแก้ไข ลบ ล้าง และสร้างสไตล์ตารางใหม่
- **แท็บมุมมองเรียบร้อยขึ้น** ปุ่มบานหน้าต่างนำทาง ตัวอย่างก่อนพิมพ์ และความกว้างหน้า แสดงชื่อสองบรรทัด กลุ่ม **แสดง** เรียงเป็นสามแถว (ไม้บรรทัดกับเส้นตาราง / ขอบเขตข้อความ / ซ่อนพื้นที่ว่าง) บานหน้าต่างนำทางแยกตาราง รูปภาพ รูปวาด และที่คั่นหน้า
- **บานหน้าต่างสไตล์ใช้พื้นที่น้อยลง** ส่วนหัวเหลือสองบรรทัด ปุ่มรองเป็นไอคอนพร้อมคำอธิบายเมื่อชี้ค้างไว้ เหลือพื้นที่ให้รายการสไตล์มากขึ้น และมีปุ่มสลับแสดงสไตล์ตามลำดับชั้น
- **แก้ไขสไตล์เป็นภาษาไทยครบขึ้น** ป้ายในหน้าต่างแก้ไขสไตล์และชื่อสไตล์ในตัวเป็นภาษาไทยทั้งหมด (ไม่เปลี่ยนชื่อสไตล์ในเอกสาร) เพิ่มปุ่มรีเซ็ต **คืนค่าตามสไตล์แม่** ตัวเลือกฟอนต์เอเชียตะวันออก และหน้า **พื้นที่** สำหรับสีพื้นย่อหน้า ค่าตัวอักษรตัวแรกขนาดใหญ่ (Drop Cap) ในสไตล์ไม่หายเมื่อบันทึกเป็น .docx
- **ริบบิ้นเรียบง่ายขึ้นตั้งแต่เปิดใช้** แท็บ วาด, จดหมาย, ช่วยเหลือ, นักพัฒนา และ Zotero ซ่อนไว้ก่อน เปิดได้ใน **ปรับแต่งริบบิ้น** ส่วนชื่อกลุ่มเปิดได้ใน ไฟล์ › ตัวเลือก › ทั่วไป
- **เตือนเมื่อเปิดบนเบราว์เซอร์แท็บเล็ต** มีข้อความภาษาไทยแจ้งข้อจำกัดของการใช้งานบนแท็บเล็ต ปิดแล้วจะไม่ขึ้นซ้ำ
- **วางจากเมนูในเบราว์เซอร์** ขอข้อความ HTML และรูปจากคลิปบอร์ดแล้ววางตามที่ได้ หากอ่านคลิปบอร์ดไม่ได้จะแจ้งในแถบสถานะ

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ รบกวนกดปุ่ม **แจ้งปัญหา** ข้างปุ่มแชร์ในโปรแกรม ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
