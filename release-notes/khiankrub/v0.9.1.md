# KhianKrub Web v0.9.1

_เผยแพร่ 28 ต.ค. 2569 · Published 2026-10-28_

[เปิดใช้งาน KhianKrub / Open KhianKrub](https://khiankrub.app)

## ภาษาไทย

เขียนครับ เวอร์ชันเว็บ v0.9.1 พร้อมให้ใช้งานฟรีผ่านเบราว์เซอร์

**ซอร์สโค้ดของแอปเว็บเป็นส่วนตัว และไม่ได้เผยแพร่เป็นโอเพนซอร์ส** คลังนี้มีเฉพาะไฟล์เว็บไซต์ที่คอมไพล์แล้ว ส่วนประกอบและฟอนต์ของบุคคลที่สามยังคงอยู่ภายใต้สัญญาอนุญาตของแต่ละรายการ ไฟล์ดาวน์โหลดที่ GitHub ตั้งชื่อว่า “Source code” เป็นไฟล์จากคลังเว็บไซต์นี้ ไม่ใช่ซอร์สโค้ดของแอปเว็บ.

- **Google Drive:** จดจำการเชื่อมต่อระหว่างการเข้าใช้งาน และเชื่อมต่อกลับอัตโนมัติเมื่อโหลดหน้าใหม่ในเบราว์เซอร์เดิม
- **ฟอนต์ SIPA ครบ 13 ตระกูล:** พร้อมใช้งานในแอปโดยไม่ต้องติดตั้งฟอนต์เพิ่ม
- **แก้ไขเมนูคลิกขวา:** ตาราง ชื่อสไตล์ในแผงสไตล์ และเลขหัวข้อ
- **เพิ่มไอคอนในเมนูคลิกขวา:** ตาราง พื้นที่ว่างบนหน้าเอกสาร และเลขหัวข้อ
- **เพิ่มหน้าข้อมูลเกี่ยวกับแอปและนโยบายความเป็นส่วนตัว:** อธิบายการใช้งานและการจัดการข้อมูล Google Drive

## English

KhianKrub Web v0.9.1 is available to use free in your browser.

**The web app’s source code is private and is not published as open source.** This repository contains compiled website files only. Third-party components and fonts retain their respective licenses. GitHub’s automatically generated “Source code” downloads contain files from this website repository, not the web app’s application source code.

- **Google Drive:** Remembers your connection between visits and reconnects automatically after reloading in the same browser.
- **All 13 SIPA font families:** Available in the app without installing extra fonts.
- **Fixed right-click menus:** Tables, style names in the Styles panel, and heading numbers.
- **Added context-menu icons:** Tables, empty page space, and heading numbers.
- **Added About and privacy-policy pages:** Explain the app and how Google Drive data is handled.
