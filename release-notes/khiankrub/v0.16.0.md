# KhianKrub Web v0.16.0

_เผยแพร่ 13 พ.ย. 2569 · Published 2026-11-13_

13 พฤศจิกายน 2569
[เปิดใช้งาน KhianKrub](https://khiankrub.app/) · [KrubOffice](https://kruboffice.app/)

**เขียนครับบนเว็บ (KhianKrub Web) รุ่น 0.16.0**

## ใหม่ในรุ่นนี้

- **ไอคอนชุดใหม่ มาตรฐานเดียวกันทั้ง KrubOffice** ไอคอนเส้นบางที่วาดใหม่ในเขียนครับ ตอนนี้ใช้ร่วมกับคิดครับและพูดครับแล้ว ปุ่มที่ทำงานเหมือนกันจึงหน้าตาเหมือนกันทุกโปรแกรม
- **แถบเครื่องมือแบบใหม่: ปุ่มสองขนาด ไม่เกินสองแถว** คำสั่งหลักเป็นปุ่มใหญ่มีชื่อกำกับ ปุ่มจัดรูปแบบเป็นไอคอนล้วน ชี้ค้างไว้เพื่อดูชื่อและปุ่มลัด แถบเครื่องมือเตี้ยลง เหลือพื้นที่เอกสารมากขึ้น ปุ่มมุมกลุ่มที่เปิดหน้าต่างตั้งค่าถูกนำออก หน้าต่างเหล่านั้นยังเปิดได้จากเมนูที่เกี่ยวข้อง คลิกขวา และปุ่มลัดเดิม
- **พับเป็นเล่ม** ตั้งค่าหน้ากระดาษ › หลายหน้า › พับเป็นเล่ม จัดหน้าสำหรับพิมพ์สองหน้าแล้วพับเป็นสมุด และส่งออก PDF แบบเรียงหน้าสำหรับพับได้
- **ปุ่มเลขไทย** ข้างปุ่มกระจายแบบไทย เปลี่ยนตัวเลขในข้อความที่เลือกเป็นเลขไทย (๑๒๓)
- **ซ่อนเลขหน้าเฉพาะหน้า** คลิกขวาที่หัวกระดาษหรือท้ายกระดาษ แล้วเลือก **ซ่อนเลขหน้าในหน้านี้** เลขหน้าถัดไปยังนับต่อตามปกติ และเปิดใน Word ได้เหมือนกัน
- **กำหนดขนาดรูปภาพ รูปร่าง และแผนภูมิจากแถบเครื่องมือ** เป็นเซนติเมตร (นิ้วเมื่อใช้ภาษาอังกฤษ)
- **แท็บของรูปภาพ ตาราง รูปร่าง แผนภูมิ และสมการเป็นภาษาไทยครบ**
- **ตั้งแท็บริบบิ้นไว้กึ่งกลางหรือชิดซ้าย** ได้ในหน้าต่าง **ปรับแต่งริบบิ้น**

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ รบกวนกดปุ่ม **แจ้งปัญหา** ข้างปุ่มแชร์ในโปรแกรม ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
