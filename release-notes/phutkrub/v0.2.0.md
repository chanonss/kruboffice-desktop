# PhutKrub Web v0.2.0

_เผยแพร่ 31 ต.ค. 2569 · Published 2026-10-31_

[เปิดใช้งาน PhutKrub / Open PhutKrub](https://phutkrub.app/) · [KrubOffice](https://kruboffice.app/)

## ภาษาไทย

**พูดครับบนเว็บ (PhutKrub Web) v0.2.0** ปรับหน้าตาให้เป็นแบบเดียวกับ เขียนครับ ในโทนสีของพูดครับครับ

- **แถบด้านบนสีส้มอิฐ** (สีเดียวกับไอคอน) รวมแถบชื่อและแท็บเข้าด้วยกัน ตัวอักษรและไอคอนสีขาว แท็บที่เปิดอยู่เป็นสีขาวต่อเนื่องไปกับริบบิ้นที่เป็นแถบขาวเรียบ
- **สีทองเมื่อชี้และเมื่อเลือก** ปุ่ม เมนู และรายการต่าง ๆ ขึ้นสีทองอ่อนเมื่อเอาเมาส์ไปชี้ และมีกรอบสีทองเมื่อเลือก ปุ่ม "นำเสนอ" และแท็บเฉพาะวัตถุเป็นสีทอง
- เมนูด้านข้างของหน้า ไฟล์ เป็นสีเดียวกับแถบด้านบน
- หน้าโหลดใช้สีส้มอิฐเป็นพื้นหลัง

## English

**PhutKrub Web v0.2.0** gives the app KhianKrub's look, in PhutKrub's own colour.

- **A coral top band** (the app icon's colour) joins the title bar and the tab strip, with white text and icons. The active tab is white and runs on into a flat white ribbon.
- **Gold hover and selection.** Buttons, menus and lists light up in pale gold on hover and get a gold outline when selected. The Present button and contextual tabs are gold.
- The File page's side menu is the same coral.
- The loading screen uses the coral as its background.

Based on [DeckCraft](https://github.com/storytold/deckcraft) by the ArtCraft team, adapted for Thai users by Chanon Sarasuk. The source code of this adaptation is currently private; this repository holds the compiled site only. Third-party components and fonts keep their own licences (see `ATTRIBUTION.md` and `fonts/`).
