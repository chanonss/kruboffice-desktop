## ภาษาไทย

**พูดครับบนเว็บ (PhutKrub Web) v0.1.0** รุ่นทดลองแรกของโปรแกรมทำงานนำเสนอภาษาไทยและภาษาอังกฤษ ใช้ฟรีในเบราว์เซอร์ครับ

- **เมนูภาษาไทย** เปิดครั้งแรกเป็นภาษาไทย สลับเป็นภาษาอังกฤษได้ และโปรแกรมจำค่าที่เลือกไว้
- **ฟอนต์ไทย** เมนูใช้ Sarabun สไลด์ใหม่ใช้ TH Sarabun New
- สร้างสไลด์ ใส่รูปร่าง รูปภาพ ตาราง แผนภูมิ ใส่การเปลี่ยนสไลด์และภาพเคลื่อนไหว เปิดและบันทึกไฟล์ `.pptx` และนำเสนอแบบเต็มจอ
- ทำงานในเบราว์เซอร์ของคุณทั้งหมด ไฟล์ไม่ถูกส่งไปที่ใด

**ยังอยู่ระหว่างพัฒนา** ข้อความบางส่วน เช่น ชื่อธีม แถบสถานะ และกล่องโต้ตอบบางหน้า ยังเป็นภาษาอังกฤษ

พัฒนาต่อยอดจาก [DeckCraft](https://github.com/storytold/deckcraft) โดยทีม ArtCraft ปรับปรุงสำหรับผู้ใช้ภาษาไทยโดย Chanon Sarasuk ไม่ใช่ผลิตภัณฑ์ของ ArtCraft

**ซอร์สโค้ดของฉบับปรับปรุงนี้เป็นส่วนตัวในขณะนี้** คลังนี้มีเฉพาะไฟล์เว็บไซต์ที่คอมไพล์แล้ว ไฟล์ดาวน์โหลด “Source code” ของ GitHub คือไฟล์จากคลังเว็บไซต์นี้ ไม่ใช่ซอร์สโค้ดของแอป ส่วนประกอบและฟอนต์ของบุคคลที่สามอยู่ภายใต้สัญญาอนุญาตของแต่ละรายการ (ดู `ATTRIBUTION.md` และโฟลเดอร์ `fonts/`)

## English

**PhutKrub Web v0.1.0** is the first early release of a free presentation app for Thai and English that runs in the browser.

- **Thai interface.** It opens in Thai on a first visit, switches to English, and remembers your choice.
- **Thai fonts.** Menus use Sarabun; new slides use TH Sarabun New.
- Make slides with shapes, pictures, tables and charts, add transitions and animations, open and save `.pptx`, and present full screen.
- Everything runs in your browser; your files are not uploaded anywhere.

**Work in progress:** some text (theme names, the status bar, some dialogs) is still English.

Based on [DeckCraft](https://github.com/storytold/deckcraft) by the ArtCraft team, adapted for Thai users by Chanon Sarasuk. It is not an ArtCraft product.

**The source code of this adaptation is currently private.** This repository contains compiled website files only; GitHub's "Source code" downloads are files from this website repository, not the app's source. Third-party components and fonts keep their own licences (see `ATTRIBUTION.md` and `fonts/`).
