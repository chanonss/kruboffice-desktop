# PhutKrub Web v0.7.0

_เผยแพร่ 13 พ.ย. 2569 · Published 2026-11-13_

[เปิดใช้งาน PhutKrub](https://phutkrub.app/) · [KrubOffice](https://kruboffice.app/)

**พูดครับบนเว็บ (PhutKrub Web) รุ่น 0.7.0**

## ใหม่ในรุ่นนี้

- **ไอคอนชุดใหม่ มาตรฐานเดียวกันทั้ง KrubOffice** ไอคอนทุกตัววาดใหม่เป็นเส้นบางแบบเดียวกับเขียนครับและคิดครับ รวมถึงภาพตัวอย่างการเปลี่ยนสไลด์และภาพเคลื่อนไหว
- **แถบเครื่องมือแบบใหม่: ปุ่มสองขนาด ไม่เกินสองแถว** คำสั่งหลักเป็นปุ่มใหญ่มีชื่อกำกับ ปุ่มจัดรูปแบบเป็นไอคอนล้วน ชี้ค้างไว้เพื่อดูชื่อ หน้าต่างแบบอักษร ย่อหน้า และขนาดและตำแหน่ง ยังเปิดได้จากคลิกขวาและเมนูที่เกี่ยวข้อง
- **ภาษาไทยในแถบเครื่องมือเรียบร้อยขึ้น** ชื่อภาพเคลื่อนไหวไม่ถูกตัด ช่องเสียงของการเปลี่ยนสไลด์เป็นภาษาไทย และช่องติ๊กไม่ทับกัน
- **เลือกภาษาของโปรแกรม** (ไทย / English) ได้ใน ไฟล์ › ตัวเลือก
- **แท็บของรูปภาพ ตาราง และ SmartArt เรียงใหม่** ให้อ่านง่ายขึ้น และเมนูเส้นขอบตารางมีภาพตัวอย่างทุกแบบ
- **ใช้ฟอนต์เมนูของเครื่อง** บนเว็บเลือกได้ใน ไฟล์ › ตัวเลือก และใช้ให้อัตโนมัติเมื่อเบราว์เซอร์อนุญาตแล้ว

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/phutkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
