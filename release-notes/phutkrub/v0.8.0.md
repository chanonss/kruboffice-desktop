# PhutKrub Web v0.8.0

_เผยแพร่ 16 พ.ย. 2569 · Published 2026-11-16_

[เปิดใช้งาน PhutKrub](https://phutkrub.app/) · [KrubOffice](https://kruboffice.app/)

**พูดครับบนเว็บ (PhutKrub Web) รุ่น 0.8.0**

## ใหม่ในรุ่นนี้

- **มุมมองผู้นำเสนอบนจอที่สอง** เปิดมุมมองผู้นำเสนอแล้วเริ่มนำเสนอ สไลด์จะเต็มจอบนจอภายนอก ส่วนโน้ตและสไลด์ถัดไปอยู่บนจอของเรา บนเว็บใช้ได้ใน Chrome และ Edge (เบราว์เซอร์จะขออนุญาตจัดการหน้าต่างครั้งแรก)
- **แผงด้านขวาแทนแท็บของวัตถุ** คลิกที่รูปร่าง รูปภาพ ตาราง แผนภูมิ หรือ SmartArt แล้วแผงจัดรูปแบบจะเปิดทางขวาเอง แทนแท็บที่เคยโผล่บนแถบเครื่องมือ แผงอยู่ในช่องเดียวกันและเปิดค้างไว้ สไลด์จึงไม่ขยับไปมา
- **แผงรูปร่างแบบเดียวกันทั้ง KrubOffice** หมวด พื้นที่ เส้น เอฟเฟกต์ และตำแหน่งและขนาด เรียงเหมือนเขียนครับและคิดครับ และตั้งความโปร่งใสของเส้นได้แล้ว
- **ฝังฟอนต์ไว้ในไฟล์ .pptx** ไฟล์ › ตัวเลือก › บันทึก เลือกฝังเฉพาะตัวอักษรที่ใช้ (ไฟล์เล็ก) หรือฝังทุกตัวอักษร ฟอนต์อังกฤษที่ฝังไว้ PowerPoint นำไปใช้ได้แล้ว ส่วนฟอนต์ไทยที่ฝังไว้ PowerPoint ยังไม่นำไปใช้ กำลังหาสาเหตุ
- **ทำสำเนาสไลด์ด้วย Cmd+D (Ctrl+D บน Windows)** เมื่ออยู่ในรายการสไลด์หรือไม่ได้เลือกรูปร่างใด ถ้าเลือกรูปร่างอยู่ จะทำสำเนารูปร่างเหมือนเดิม
- **หน้าเริ่มต้นดูง่ายขึ้น** แต่ละธีมมีการ์ดเดียว พร้อมลิงก์ **สไลด์ตัวอย่าง** ใต้การ์ด สไลด์ตัวอย่างแสดงเป็นปึกสไลด์จริงพร้อมชื่อธีม ไม่ซ้ำกับการ์ดธีมอีก
- **เมนูรูปร่างเป็นภาษาไทย** ชื่อกลุ่ม เช่น เส้น สี่เหลี่ยมผืนผ้า รูปร่างพื้นฐาน ลูกศรแบบทึบ ผังงาน
- **ภาษาไทยครบขึ้น** แผงพื้นหลังและแผงจัดรูปแบบรูปร่าง แถบสถานะ และชื่อหน้าต่าง
- **ปักหมุดฟอนต์ไว้บนสุด** ชี้ที่ชื่อฟอนต์ในรายการแล้วกดหมุด ฟอนต์ที่ใช้บ่อยจะอยู่บนสุดเสมอ
- **ไฟล์ › ตัวเลือก จัดเป็นหมวด** ทั่วไป การตรวจทาน บันทึก ภาษา และขั้นสูง หน้าตาเดียวกันทั้งสามโปรแกรม เลือกธีมสว่างหรือมืด และขนาดของหน้าจอโปรแกรม (75 ถึง 175%) จากรายการ
- **แถบด้านบนแบบเดียวกันทั้ง KrubOffice** บันทึก เลิกทำ (พร้อมรายการย้อนหลัง) ทำซ้ำ และเริ่มนำเสนอตั้งแต่ต้น แถบเครื่องมือสูงเท่ากับอีกสองโปรแกรม
- **ไอคอนชัดขึ้น** ไอคอนส่วนใหญ่มาจากชุด Tabler Icons (สัญญาอนุญาต MIT)

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/phutkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
