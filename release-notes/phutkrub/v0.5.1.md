# PhutKrub Web v0.5.1

_เผยแพร่ 6 พ.ย. 2569 · Published 2026-11-06_

[เปิดใช้งาน PhutKrub](https://phutkrub.app/) · [KrubOffice](https://kruboffice.app/)

**พูดครับบนเว็บ (PhutKrub Web) รุ่น 0.5.1**

## ใหม่ในรุ่นนี้

- **ไฟล์ › เกี่ยวกับ แบบเดียวกับเขียนครับ** แสดงชื่อพูดครับ รุ่นของโปรแกรม คำอธิบายภาษาไทย ลิงก์หน้าโครงการ และลิงก์โครงการต้นฉบับ DeckCraft เหมือนกันทั้งสามโปรแกรมใน KrubOffice ลิงก์ Discord ของโครงการต้นฉบับนำออกแล้ว

รายการใหม่ของรุ่น 0.5.0 ดูได้ที่[หน้ารุ่น 0.5.0](https://github.com/chanonss/phutkrub-web/releases/tag/v0.5.0)

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/phutkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ

พัฒนาต่อยอดจาก [DeckCraft](https://github.com/storytold/deckcraft) โดยทีม ArtCraft ปรับปรุงสำหรับผู้ใช้ภาษาไทยโดย Chanon Sarasuk ไม่ใช่ผลิตภัณฑ์ของ ArtCraft และไม่เกี่ยวข้องกับ Microsoft
