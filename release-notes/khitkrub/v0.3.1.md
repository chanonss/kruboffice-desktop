# KhitKrub Web v0.3.1

_เผยแพร่ 6 พ.ย. 2569 · Published 2026-11-06_

[เปิดใช้งาน KhitKrub](https://khitkrub.app/) · [KrubOffice](https://kruboffice.app/)

**คิดครับบนเว็บ (KhitKrub Web) รุ่น 0.3.1**

## ใหม่ในรุ่นนี้

- **ไฟล์ › เกี่ยวกับ (เดิมชื่อ บัญชี) แบบเดียวกับเขียนครับ** แสดงชื่อคิดครับ รุ่นของโปรแกรม คำอธิบายภาษาไทย ลิงก์หน้าโครงการ และลิงก์โครงการต้นฉบับ GridCraft เหมือนกันทั้งสามโปรแกรมใน KrubOffice

รายการใหม่ของรุ่น 0.3.0 ดูได้ที่[หน้ารุ่น 0.3.0](https://github.com/chanonss/khitkrub-web/releases/tag/v0.3.0)

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/khitkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ

พัฒนาต่อยอดจาก [GridCraft](https://github.com/storytold/gridcraft) โดยทีม ArtCraft ปรับปรุงสำหรับผู้ใช้ภาษาไทยโดย Chanon Sarasuk ไม่ใช่ผลิตภัณฑ์ของ ArtCraft และไม่เกี่ยวข้องกับ Microsoft
