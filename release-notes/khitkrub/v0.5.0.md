# KhitKrub Web v0.5.0

_เผยแพร่ 13 พ.ย. 2569 · Published 2026-11-13_

[เปิดใช้งาน KhitKrub](https://khitkrub.app/) · [KrubOffice](https://kruboffice.app/)

**คิดครับบนเว็บ (KhitKrub Web) รุ่น 0.5.0**

## ใหม่ในรุ่นนี้

- **ไอคอนชุดใหม่ มาตรฐานเดียวกันทั้ง KrubOffice** ไอคอนทุกตัววาดใหม่เป็นเส้นบางแบบเดียวกับเขียนครับและพูดครับ ปุ่มที่ทำงานเหมือนกันหน้าตาเหมือนกันทุกโปรแกรม
- **แถบเครื่องมือแบบใหม่: ปุ่มสองขนาด ไม่เกินสองแถว** คำสั่งหลักเป็นปุ่มใหญ่มีชื่อกำกับ ปุ่มจัดรูปแบบเป็นไอคอนล้วน ชี้ค้างไว้เพื่อดูชื่อ หน้าต่างจัดรูปแบบเซลล์ยังเปิดได้จาก Ctrl+Shift+F เมนู **รูปแบบ** ในกลุ่มเซลล์ และ **รูปแบบตัวเลขเพิ่มเติม…**
- **สมุดงานใหม่ใช้ฟอนต์ Sarabun** ทั้งตัวไทย ตัวอังกฤษ และตัวเลขจากฟอนต์เดียวกัน (สมุดงานเดิมใช้ฟอนต์ของตัวเอง)
- **ย้ายหรือคัดลอกชีตไปสมุดงานอื่น** ได้ทั้งสมุดงานใหม่และสมุดงานอื่นที่เปิดอยู่
- **แท็บรูปแบบรูปภาพและรูปแบบรูปร่าง** พร้อมช่องความสูงและความกว้างสำหรับรูปภาพ รูปร่าง และแผนภูมิ
- **หน้าต่างจัดรูปแบบเซลล์ขนาดคงที่** เปลี่ยนแท็บแล้วหน้าต่างไม่กระตุก
- **ใช้ฟอนต์เมนูของเครื่อง** บนเว็บเลือกได้ใน ไฟล์ › ตัวเลือก › ทั่วไป และใช้ให้อัตโนมัติเมื่อเบราว์เซอร์อนุญาตแล้ว

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/khitkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
