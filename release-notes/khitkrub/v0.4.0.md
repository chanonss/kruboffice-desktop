# v0.4.0

_เผยแพร่ 7 พ.ย. 2569 · Published 2026-11-07_

[เปิดใช้งาน KhitKrub](https://khitkrub.app/) · [KrubOffice](https://kruboffice.app/)

**คิดครับบนเว็บ (KhitKrub Web) รุ่น 0.4.0**

## ใหม่ในรุ่นนี้

- **ตัวควบคุมฟอร์ม: ปุ่ม แถบเลื่อน และปุ่มหมุน** แทรก › ปุ่ม / แถบเลื่อน / ปุ่มหมุน วาดลงบนชีตได้ แถบเลื่อนและปุ่มหมุนเปลี่ยนตัวเลขในเซลล์ที่ลิงก์ไว้ ส่วนปุ่มกำหนดให้เรียกแมโครหรือคำสั่งได้ (คลิกขวา › กำหนดการทำงาน… / จัดรูปแบบตัวควบคุม…) หน้าต่างตั้งค่าเป็นภาษาไทยทั้งหมด บันทึกเป็น `.xlsx` แล้วเปิดใน Excel ได้
- **วางทั้งคอลัมน์หรือทั้งแถวได้แล้ว** เดิมการวางข้อมูลที่คัดลอกมาทั้งคอลัมน์หรือทั้งแถวอาจทำให้โปรแกรมหยุดทำงาน
- **"ตั้งค่าความแม่นยำตามที่แสดง" คำนวณจริง** เมื่อเปิดตัวเลือกนี้ ผลของสูตรจะปัดตามรูปแบบตัวเลขของเซลล์ก่อนนำไปใช้ต่อ เหมือน Excel
- **กล่องโต้ตอบที่เลือกช่วงบนชีต** (เช่น Goal Seek และ Solver) จำชีตที่เปิดไว้ คลิกเซลล์ที่เลือกอยู่ก็เลือกได้ และรับชื่อชีตที่มีเครื่องหมายคำพูด
- **แผนภูมิโดนัท** ข้อมูลหลายชุดวาดเป็นวงซ้อนกันถูกต้อง
- **ลิงก์ที่เปิดโดยอัตโนมัติจะถามก่อน** ไม่เปิดเว็บไซต์เองโดยไม่ได้ยืนยัน
- **ไฟล์ Excel ขนาดใหญ่ผิดปกติ** ไฟล์ที่ระบุขนาดเกินจริงจะไม่ใช้หน่วยความจำจนเบราว์เซอร์ค้าง
- **ภาษาไทยครบขึ้น** ป้ายที่ยังเป็นภาษาอังกฤษ เช่น แก้ไข/เปิด/เอาไฮเปอร์ลิงก์ออก ตัวเลือกการแสดงผลของเวิร์กบุ๊ก (แท็บชีต แถบเลื่อน) และการเน้นแถวของเซลล์ที่เลือกอยู่ เป็นภาษาไทยแล้ว

ใช้ได้ฟรีบนคอมพิวเตอร์และ iPad ยังไม่รองรับโทรศัพท์มือถือ หากพบปัญหาหรือมีข้อเสนอแนะ แจ้งได้ที่หน้า [Issues](https://github.com/chanonss/khitkrub-web/issues) ขอบคุณทุกคนที่ช่วยทดลองใช้ครับ
